Set up your Fire TVUndo setup

Amazon doesn't let apps on a Fire TV use that TV's own debugging connection, so MaterialTV's setup runs from another device: an Android phone or a computer on the same Wi-Fi.

Put your Fire TV back the way it was: switch Amazon's apps back on, restore settings, and remove what setup installed. Undo runs from an Android phone or a computer on the same Wi-Fi.

iPhone can't do this — use a computer

iPhone and iPad can't talk to a Fire TV's debugging connection. Use a Windows, Mac or Linux computer (instructions below), or an Android phone, on the same Wi-Fi as the TV.

With an Android phone

The same MaterialTV app you installed on the TV also works as a setup remote on an Android phone. It connects to the TV over Wi-Fi and does the setup for you.

Open MaterialTVOpen MaterialTV to undo setup Download MaterialTV for your phone (APK)

If MaterialTV isn't on your phone yet, Open MaterialTV downloads it instead.

The Open MaterialTV button only works in Chrome on an Android phone. Scan the TV's QR code with the phone to get there.

  1. Install MaterialTV on the phone. Tap Open MaterialTV or the APK link. If Android asks, allow your browser to install unknown apps, then tap Install.

  2. Come back here and tap Open MaterialTV (or scan the TV's QR code again), so the app knows which TV to set uprestore.

  3. In MaterialTV, check the code matches the TV and tap Set upUndo setup.

  4. On the TV, when it asks "Allow USB debugging?", tick Always allow and press OK on the remote. Then follow the steps on the phone.

Your phone and the TV must be on the same Wi-Fi network (or both connected to the same Tailscale network).

With a Windows PC

Open PowerShell (press Start, type PowerShell, press Enter), paste this command and press Enter:

PowerShell
$env:M3_TV="192.168.1.50"; irm https://raw.githubusercontent.com/Brick-Bread/MaterialTV/main/scripts/setup.ps1 | iex

Prefer to read it first?

  1. Download setup.ps1. If it opens as text, press Ctrl+S and save it as setup.ps1 in your Downloads folder. Read it in any text editor.

  2. In PowerShell, run:

    PowerShell, from your Downloads folder
    cd $HOME\Downloads
powershell -ExecutionPolicy Bypass -File setup.ps1 -Tv 192.168.1.50

With a Mac or Linux computer

Open Terminal (on a Mac: press Cmd+Space, type Terminal, press Enter), paste this command and press Enter:

Terminal
curl -fsSL https://raw.githubusercontent.com/Brick-Bread/MaterialTV/main/scripts/setup.sh | bash -s -- --tv 192.168.1.50

Prefer to read it first?

Download setup.sh, or fetch it, read it, then run it:

Terminal
curl -fsSLo setup.sh https://raw.githubusercontent.com/Brick-Bread/MaterialTV/main/scripts/setup.sh
less setup.sh
bash setup.sh --tv 192.168.1.50

Before you start

The TV needs ADB debugging switched on. You only do this once.

  1. On the Fire TV open Settings › My Fire TV › Developer options and turn on ADB debugging.

  2. No Developer options? Open Settings › My Fire TV › About, select your device name seven times, then go back.

  3. Keep the TV on and on the same Wi-Fi as your phone or computer until setupundo has finished.

What setup can do

Every step is optional, and everything can be undone.

You choose which steps run

  • MaterialTV permissions: take over the Home button and hold-Home, the display filter, sleep timer, screensaver and updates.
  • Debloat & privacy using the dumbtv lists: switch off Amazon's ad and tracking apps and apply privacy settings. Alexa can be kept.
  • Install SmartTube (ad-free YouTube for TV) from a pinned, checksum-checked release.
  • Install Tailscale from its official download and set it as the always-on VPN.

Everything can be undone

Setup records every change with the value that was there before. To reverse it:

  • On the TV, open Settings › Fire TV setup › Undo. It shows a QR code that brings you back here in undo mode.
  • Or use this page in undo mode: Undo setup.

Amazon apps are only switched off, never removed.
